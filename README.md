# Mesh Security

**Shield for jailbroken iPods: random password instead of alpine, all incoming ports closed, only the apps you allow go online, every connection logged.**

Install via the **[Reboot App Store](https://github.com/SecondTrack/reboot)** right on the iPod, or download the `.deb` from the [latest release](https://github.com/SecondTrack/security/releases/latest) and install it with `dpkg -i`.

Build it yourself with [Theos](https://theos.dev): `make package`

Part of **Reboot** by **Second Track** – new apps for old iPods.
